# Changelog

All notable changes to the Stack Junkie Agent Skills collection are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the collection follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- **Manage Codex Work:** Added connected Notion capture, evidence-backed activity fields, recoverable decision forwarding, and incremental scheduled maintenance while retaining native-only task access.

### Added

- **Project Team draft 0.1.0:** Added role contracts, independent deputy review, shared Kanban/timeline/standup records and bounded delivery guidance. The Life Explosion pilot brief is prepared for later owner review and fresh-session launch.

- **Parallel Issue Orchestration (`parallel-issue-orchestration`) 1.0.0:** Added live-state reconciliation, conflict mapping, isolated agent lanes, shared-host permission boundaries, orchestrator review, and focused publication for concurrent GitHub issue work.

## [2.0.0] - 2026-08-19

### Changed

- **Manage Codex Work (`manage-codex-work`) 2.0.0:** Replaced the custom Thread Steward scanner and state runtime with native Codex task tools.
- **Stack Junkie Style (`stack-junkie-style`) 2.0.0:** Removed compliance reports, audit levels, evidence matrices, validator scripts, and independent-review requirements while retaining the design system and direct product-preview guidance.
- **Preserve Compaction Continuity (`preserve-compaction-continuity`) 1.0.1:** Removed test-running instructions without changing its recovery runtime or integrity protections.
- **Installer:** Removed the Drive hook option and Drive-specific installation code while retaining version and copy-integrity checks.

### Removed

- Removed `repo-readiness`, `drive-project-work`, all repository test suites, tracked Git hooks, repository policies, collection validators, and validation runners.

## [1.3.0] - 2026-08-19

### Added

- **Thread Steward (`manage-codex-work`) 1.0.0:** Added read-only reconciliation of recent and active Codex conversations, a concise decision inbox, local parking, relationship detection, and validation-theatre warnings without cross-chat actions.

### Changed

- **Collection:** Established independent SemVer sources for every skill while retaining root `VERSION` for collection snapshots.

## [1.2.0] - 2026-08-18

### Added

- Added `preserve-compaction-continuity` with transcript-backed recovery, a visible post-compaction status report, and preview-first Codex hook management.

## [1.1.0] - 2026-08-12

### Fixed

- Made the Stack Junkie specimen's tabs, switch focus, narrow workbench disclosures, and persisted themes behave like the patterns they demonstrate.

## [1.0.0] - 2026-08-12

### Added

- Published `stack-junkie-style` with its visual specimen, UX references, and approved example screenshots.
- Established one cross-agent package layout for Codex, Claude Code, T3 Code provider harnesses, and other Agent Skills compatible clients.
