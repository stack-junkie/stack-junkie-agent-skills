# A format library that starts with the reader's task

The article format library now contains guidance for eight types and a complete instructional article for each: guide, troubleshooting, reference, comparison, review, news analysis, opinion and project update. The [format reference](../formats.md) links the examples and explains the reader task each serves.

The delivered change is a set of usable writing references. It gives an author more to examine than empty section names: each example makes an argument or answers a narrow question, with its evidence and limits visible in the text.

## What the examples make concrete

The [PowerShell guide](guide.md) takes a reader from a file and expected checksum to a comparison result. The [JSON troubleshooting article](troubleshooting.md) isolates one syntax failure, applies a small correction and distinguishes successful parsing from application acceptance. The [Git reference](reference.md) uses a lookup table and a spacing example instead of forcing a step-by-step narrative.

The other formats show different kinds of judgment. The [redirect comparison](comparison.md) makes a conditional choice from protocol semantics. The [Google guidance review](review.md) assesses a document without pretending to have measured search outcomes. The [Bing news analysis](news-analysis.md) separates announced preview features from observed account access. The [opinion article](opinion.md) states its own instructional position and considers an objection.

These links point to the actual delivered examples. They are evidence of the contents of the library, not evidence that a reader trial has succeeded.

## Why the library uses complete articles

A skeleton can show where a heading belongs while leaving every consequential writing decision unresolved. Complete examples expose the connection between a claim, its citation, an explanation and the reader's next step. That is the design rationale for this version.

The [reference also makes the attribution boundary explicit](../formats.md): the examples are instructional material, not approved samples of the owner's voice. Keeping that distinction visible lets the library teach structure without manufacturing a personal history.

## What remains to learn

The existence of the files does not establish that fresh writers will apply them consistently. A useful next trial would give independent writers the same brief, ask each to choose a format, then review whether their finished pieces answer the task and preserve the evidence. That trial is proposed here, not reported as complete.
