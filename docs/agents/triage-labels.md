# Triage labels

| Skill role | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the specified work. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | The maintainer has declined the work. |

Apply Wayfinder labels to maps and decision tickets as described in [tracker operations](issue-tracker.md).
