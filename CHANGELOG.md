# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Added concise bug and improvement issue workflows with reusable GitHub templates and verification-before-close guidance.
- Added required practical READMEs and full-document stale-content review whenever a README is changed.

## [1.2.0] - 2026-08-11

### Added

- Added main-first branch and worktree health reporting for repository reconciliation.
- Added required redacted Gitleaks checks for staged changes, current files, and complete history.
- Added repository-aware `.gitignore` review and one-approval reconciliation guidance.

### Changed

- Made unresolved agent branches and unsafe worktree state release blockers without building an automatic cleanup engine.

## [1.1.0] - 2026-08-11

### Changed

- Rebuilt the skill around a solo developer working primarily with coding agents.
- Replaced per-edit version bumps with curated unreleased notes and explicit release checkpoints.
- Made root `VERSION` the canonical source and added deterministic mirror checks.
- Replaced broad release scripts with one repository policy command and tracked local hooks.
- Made GitHub Actions opt-in instead of generated by default.

### Added

- Added explicit repository-edit boundaries, concurrent-agent ownership rules, and evidence-based handoffs.
- Added Conventional Commit and `Release-Impact` enforcement.
- Added independent release-review requirements that distinguish self-review from independent verification.

## [0.1.0-alpha.0] - 2026-06-06

### Added

- Created the initial `repo-readiness` skill source repository.
